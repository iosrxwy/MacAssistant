## 기능

시스템 개요, 정리, App 복구, 메모리, 네트워크, 262개 명령. DEB, DYLIB, IPA, Mach-O, 서명(Beta). 변경 전 미리보기. 텔레메트리 없음.

## 빌드

```bash
git clone https://github.com/iosrxwy/MacAssistant.git
cd MacAssistant
./build_app.sh release universal
```
