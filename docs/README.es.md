## Funciones

Resumen del sistema, limpieza, reparación de apps, memoria, red y 262 comandos. DEB, DYLIB, IPA, Mach-O y firma (Beta). Vista previa antes de cada cambio. Sin telemetría.

## Descarga

[Releases](https://github.com/iosrxwy/MacAssistant/releases) · macOS 13+. Esta beta es **ad-hoc y no está notarizada**. Si macOS la bloquea: ábrela una vez, luego **Ajustes del Sistema → Privacidad y seguridad → Abrir de todos modos**.

[X @iOSRXWY](https://x.com/iOSRXWY) · [Telegram](https://t.me/iosrxwy)

## Compilar

```bash
git clone https://github.com/iosrxwy/MacAssistant.git
cd MacAssistant
./build_app.sh release universal
```
