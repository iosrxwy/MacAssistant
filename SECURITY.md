# Security Policy

## Supported versions

Please report issues against the latest release on [Releases](https://github.com/iosrxwy/MacAssistant/releases), or against current `master`.

## Report a vulnerability

Do **not** open a public Issue for a security problem.

Use GitHub’s private advisory form:

https://github.com/iosrxwy/MacAssistant/security/advisories/new

Include:

- What the issue is, and who it affects
- Steps to reproduce, or a proof that stays within a machine you own
- App version or commit, macOS version, and chip

You should get a first response within 7 days. Please do not publish an exploit or a write-up until a fix is released, or we have agreed a date.

This project does not accept reports whose goal is detection bypass, DRM, anti-cheat, payment or access-control circumvention.
